# SAINT_OS // ULTRA

This build pushes the previous SAINT_OS prototype into interactive-music-video territory.

## Added in ULTRA
- Custom GLSL full-screen post-processing
- Real chromatic aberration
- Shader-driven screen tearing and warping
- Audio-reactive distortion intensity
- 7,000-particle WebGL field
- Mouse-reactive 3D camera
- Scroll-driven camera movement
- Progressive visual decay
- Click-and-hold corruption mode
- Scene-aware shader intensity
- Cursor trail, CRT overlays, film monitors, archive parallax, CONFESS terminal, hidden private area

Run with VS Code Live Server. The site loads Three.js from jsDelivr, so it needs an internet connection unless you host Three.js locally. Audible sound begins after ENTER CHURCH because browsers block unsolicited audible autoplay.
